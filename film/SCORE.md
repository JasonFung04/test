# 光年 LIGHT-YEARS — 配乐与声音提示表 v1.1

**以 `engine/timeline.py`（导出为 `build/timeline.json`）为唯一时间源。** 下表括号里的秒数只供阅读；实现时一律按事件名引用（例如 `E["palm_tone"]`），这样时间线改动后声音会自动跟随。

## 全局规则

1. **全片只有一次重击**：I8 光壳爆发（`burst`）。片头片名不用 BRAAM，也不用任何预告片式重击。
2. **真静默**要做成数字静默，混响尾巴也一起切掉：`cut_black` 之后到 `act1`、`hard_silence` 那一刻、`cornea_touch` 到 `pullout`。
3. **信使音**：玻璃音 A5（880 Hz）只在四处出现，且必须是同一个音色补丁：片名 `title_tone`、掌心 `palm_tone`、金星 `gold_star_tone`、片尾最后一个音。
4. **动机**："问"是 A5–D6–E6–F6（D 小调），"答"是 A5–D6–E6–F♯6（D 大调）。
5. 响度：网络母版整合响度 −16 LUFS，真峰值 ≤ −1 dBTP。动态范围要大，`burst` 是全片最响的一刻，安静段落的短期响度应在 −35 到 −45 LUFS。
6. 48 kHz、24-bit、立体声。输出分轨 `music` / `sfx` / `amb` 和一个 `master`。

## 音色设计

- **玻璃音（信使音）**：加法合成，泛音为 1×、2.76×、5.40×、8.93×，振幅 1 / 0.35 / 0.15 / 0.06。起音约 5 ms，带一点"叮"的瞬态；基音衰减约 6 秒，高次泛音衰减更快。两个副本相互失谐 ±0.8 Hz 产生拍频，送入大厅混响。
- **钢片琴**：泛音 1×、4×、10×，快速衰减（1.2–2 秒）。
- **合唱垫**：每个音用 7 个锯齿波，相互失谐 ±8 音分，经共振峰滤波。元音 "oo" 为 300/870/2240 Hz，"ah" 为 730/1090/2440 Hz。起音 1.5 秒，颤音 5 Hz、±6 音分，低通 5 kHz。
- **弦乐垫**：失谐锯齿波，低通 2.5 kHz，缓慢涨落，加极轻的擦弦噪声。
- **次低频与重击**：正弦下扫，叠加低通噪声瞬态和轻度失真。
- **混响**：用程序生成的冲激响应（指数衰减噪声，频率相关衰减，左右去相关）做卷积。四种空间：大厅（RT60 5–6 秒）、房间（0.6 秒）、洞穴（1.2 秒，带早期反射）、城市（1.5 秒，漫反射）。

## 逐段提示

### 片头（0–28）
- `room_tone_in`（1.0）：机房底噪淡入，低通粉红或棕噪声加极轻的 50 Hz 嗡声，约 −42 dBFS。
- `cursor_blinks`：光标闪烁不出声。
- `hash_key`（4.0）：一记机械键击（5 ms 噪声瞬态、约 2.2 kHz 的共鸣、约 180 Hz 的低沉底音），配 2.5 秒暗色长混响。这是"第一个痕迹"。
- `typing[]`：逐字键击，每一下有随机微差，用短房间混响。
- `credit_lines`（11.0 / 13.4 / 15.4）：三声极轻的玻璃音 D6、E6、G6（不许用 A5），约 −30 dB。
- 从 10.5 到 20.3，低频脉冲每 1.2 秒一下（45 Hz 正弦，衰减 0.5 秒），逐渐加强；20.3 停下，留 0.2 秒的屏息。
- `dissolve_start`→`swirl`（20.5–22.0）：成千上万颗细小的玻璃颗粒声，立体声散布，密度和音高（2→8 kHz 频带）一起上升。
- `swirl`→`title_tone`（22.0–23.5）：旋涡声。一条自动声像旋转的噪声带，加一个向上滑奏的多八度和弦，加逐渐长大的 D1 次低频。
- `title_tone`（23.5）：其他声音瞬间全部抽走，只剩玻璃音 A5 和它的大厅混响；下面垫一层极轻的低音合唱 "oo"（D2+A2），24.5 淡入，持续到 26.8。
- 26.5–27.0 快速收尾；`cut_black`（27.0）起真静默，持续到 28.0。

### 第一幕（28–81）
- 恒星呼吸：从 `star_breath_first` 起每 `star_breath_period` 秒一次峰值（28.5、32.5……）。每次呼吸用 32 Hz 与 48 Hz 正弦加低通噪声，峰前 1.8 秒涨起，峰后 2 秒落下，约 −18 dBFS，要能感到而不是听到。
- 等离子噼啪：稀疏，约 −36 dB。D1+A1 低音持续整个第一幕，约 −30 dB。
- `choir_in`（35.0）：风声，加合唱 "oo" 的 Dm 和弦（D4-F4-A4），缓慢涨起。41.0 起加入气息般的合唱，以 3.2 秒为周期呼吸。
- `elder_looks_down`（47.8）：合唱在 50.0 前渐隐到几乎听不见。
- `palm_open`（50.3–51.3）：一口轻轻的吸气般的气流。
- `palm_tone`（51.5）：**玻璃音 A5**。
- 升起（54.0–71.8）：Dm 54–58 → B♭ 58–62 → F 62–66 → C 66–70 → Csus 70–71.8。
  - "问"动机（玻璃音）：A5 在 `lift_first`（54.5）、D6 56.5、E6 57.5、F6 58.5（延长 3 秒）；随后弦乐低八度重复：A4 62.0、D5 64.0、E5 65.0、F5 66.0。
  - 从 `lift_all`（57.0）起，温暖的上升闪烁颗粒逐渐变密，到 64.0 最密。
  - 66.0–71.8：谢泼德音阶上升，合唱渐强，次低频从 30 Hz 升到 45 Hz。71.6–71.8 反向吸气，几乎静默。
- `burst`（71.8）：**唯一的重击**。次低频从 60 Hz 下扫到 25 Hz（1.5 秒），加失真的巨大低频冲击和高频爆裂瞬态。和弦 B♭(add9)（B♭1 F2 B♭2 D3 C4 F4 D5）用铜管质感的锯齿波加合唱，71.8–73.5 涨起，然后是 F/A（73.5–75.2）。
- 74.5–`front_pass`（75.2）：前沿呼啸由左扫到右，渐强；75.2 冲击。
- `hard_silence`（76.0）：硬切静默。随后 7.2 kHz 耳鸣正弦从约 −38 dB 起淡出 4 秒；76.5 和 80.5 各有一次极弱的恒星呼吸（约 −30 dB）。

### 第二幕（81–124）
- `nebula`（81–87）：F 利底亚闪烁琶音，每 0.25 秒一个音。Fmaj9（F5 A5 C6 E6 G6）81–84，B♭maj7♯11（B♭5 D6 F6 A6 E7）84–87。配柔和的弦乐与合唱，加低通 80 Hz 的棕噪声隆隆声。
- `galaxy`（87–93）：琶音减慢变稀，停在 F(add9)（F3 C4 G4 A4）；92.0 起渐隐，93.0 静默。
- `black_card`（93.0）：静默。`fire_in`（95.0）火声淡入。
- 布隆伯斯（96.5–118）：火的噼啪与火焰低吼约 −24 dB；远处海浪每 7 秒一次（低通 600 Hz，约 −34 dB）；风声很轻。97.5–100.5 有一声极远、极轻的气息长音 D5，100.8–102.3 是 A4（约 −32 dB）。
- `strokes_parallel` 与 `strokes_cross`：每一笔配 0.45 秒的刮擦声（2–6 kHz 带通噪声，带颗粒感，音高略降），近距离收音，约 −20 dB；三条斜线更从容，每笔 0.6 秒。
- 108.2：她的一口呼气。
- 114.0–117.0：心跳般的低频脉冲（114/115/116/117），逐渐增强。117.2–118.0 反向呼啸冲进切点。
- `match_cut`（118.0）：117.7 起火声的颗粒变密；118.0 城市轰鸣进来，用 0.25 秒交叉淡化加滤波变形，让人听成同一个声音变了形。城市轰鸣由车流嘶声（300 Hz–4 kHz）、低频（40–90 Hz）、偶发远处喇叭和 100/150 Hz 电气嗡声组成。

### 第三幕（124–217.5）
- `city_tilt`（124–131）：宽立体声城市轰鸣；127 左右有一声极远的警笛（约 −40 dB）。
- `rooftop`（131）：转到屋顶视角，轰鸣退远（低通 2 kHz、−6 dB），近处有风。
  - `torch_click_fail`：干涩的塑料咔嗒；`torch_tap`：金属磕在掌心的闷响；134.0 一声细小的电流嘀；`torch_on`：咔嗒；`torch_off`：咔嗒。
- `transformer_flash`（146.0）：此刻无声。`transformer_thump`（148.0）：一记深沉的远处闷响（低通 150 Hz，长混响）加电弧噼啪尾音。
- `district_off[]`：每一环配一声下降的断电嗡鸣（180→40 Hz，0.8 秒，约 −30 dB），同时城市轰鸣减少一层（轰鸣由 14 层组成，按感知曲线逐层撤掉）。`rooftop_lamp_off`（154.2）：一声细小的"叮"，嗡声停止。
- 155.0–158.5：近乎静默，只有风声和她的呼吸（158.0）。`car_alarm`（156.0/156.4/156.8）：远处带混响的双音啁啾（约 1.4 kHz 与 2.1 kHz，每声 0.12 秒）。
- 星空（158.5–176）：160 起有稀疏的高音玻璃颗粒，到 165 逐渐变密。`theme_return`（162.0）：D 大调，D 162–166 → A/C♯ 166–170 → Bm 170–174 → G 174–176。
  - "答"动机（玻璃音）：A5 162.5、D6 164.5、E6 165.5、F♯6 166.5（延长）；弦乐：A4 170、D5 172、E5 173、F♯5 174。合唱 "ah" 在 166 轻轻进入。
- 176.0：和声转到 A sus4，压低。`gold_star_tone`（178.5）：**玻璃音 A5**，其余全部压低 6 dB。
- `photon_fall`（180.5–184.5）：一缕纤细的下行闪烁（高音谐波从 3 kHz 缓慢滑到 1.2 kHz），A sus4 垫音继续但很轻。184.5 起垫音几乎消失。
- `cornea_touch`（186.5）：**真静默**，直到 `pullout`（187.5）。
- 两个世界（187.5–200.5）：187.5 从静默里淡入一个温暖的低音 D（D2 大提琴质感，加合唱 "oo" D3）。
  - `arc_start`→`arc_end`：钢片琴或玻璃奏"答"动机 A5 188.6、D6 189.3、E6 189.8、F♯6 190.4，F♯6 与光子入眼（190.5）同时落下。
  - `orbit_start`（190.5）起主题完整呈现：D 190.5–192.5 → Bm 192.5–194.5 → G 194.5–196.5 → A 196.5–198.0 → D 198.0。`sky_red`（193.0）起加入红巨星的呼吸次低频和温暖的铜管式涨落。旋律用弦乐加合唱，音型大致为 F♯5 E5 D5 | B4 D5 E5 | G5 F♯5 E5 | E5 C♯5 | D5（从 198.0 延长）。
  - `elder_dissolve`（198.0–200.5）：和弦保持，高音颗粒上升后淡出。
- `blink`（200.5–205）：高音区柔和的 D(add9) 垫音；201.4 一口呼吸；204.8 前淡出。
- `power_return`（205–210）：电流嗡鸣上升（A1→A2 滑音，2 秒），`district_on[]` 每一环回来一层轰鸣，加一声轻微的"嗡"。音乐已经没有了。
- `rooftop_after`（210–217.5）：远处的城市轰鸣和风声，字卡只压在环境声上。

### 尾声（217.5–246）
- `torch_click_fail_final`（219.5）：干涩的咔嗒，然后 1 秒的悬念，只有环境声。`torch_tap_final`（220.6）：一声闷响。
- `torch_on_final`（220.9）：咔嗒，钢片琴**独奏**"答"动机：A5 221.0、D6 221.6、E6 222.0、F♯6 222.5（延长）。
- `beam_rise`（224.0）：上升的呼啸加风声，D(add9) 垫音进入；城市轰鸣的低通频率随上升一路下扫，230 前消失。
- 226–234 主题完整呈现：D 226 → Bm 228 → G 230 → A 232 → D(add9) 234。旋律是扩大的"答"动机：A4 226、D5 228、E5 230、F♯5 232（延长）。
- `beam_fades`（232.5）→`space`（234.0）：织体变薄，合唱散进巨大的混响；到了太空，声音辽阔而安静。
- `final_chord`（237.0）：D(add9)（D2 A2 D3 F♯3 A3 E4 F♯4），玻璃音 F♯6 延长。
- 243.5–244.0 其余全部淡出，只留 F♯6；黑场（244–246）里它衰减到静默（245.8）。

### 片尾（246–264）
- 钢片琴加垫音，慢速演奏 D 大调主题：D – Bm – G – A – D，每个和弦 3.6 秒。
- 261.5 最后一次**玻璃音 A5**，264.0 前衰减到静默。
